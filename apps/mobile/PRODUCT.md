# Product

## Register

product

## Users

The owner uses an Android phone to converse with a fast voice agent and delegate
coding work to the selected T3 thread.

## Product Purpose

Make the existing voice pipeline available in native T3 mobile, retaining
T3-owned threads, history, permissions, and settle/restore behavior.

## Brand Personality

Preserve T3's existing native components, typography, and theme. Keep chat as the
main screen and expose voice controls beside the composer.

## Anti-references

Do not embed the old Qwen web interface or replace the application with a separate
voice-only session picker.

## Design Principles

- Voice is another interaction channel in the current thread.
- Closing voice controls is distinct from ending a call.
- Recording state must remain visible and controllable.
- Context switches must never silently redirect an active conversation.

## Accessibility & Inclusion

Use Polish labels for voice controls, accessible names, large touch targets, and
the existing native theme and reduced-motion behavior.
