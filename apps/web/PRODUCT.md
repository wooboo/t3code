# Product

## Register

product

## Users

The owner uses coding-agent threads from a computer and an Android phone, with
voice as an additional way to converse and delegate work.

## Product Purpose

Embed the existing fast voice pipeline into T3 Code while retaining T3-owned
threads, history, permissions, and settle/restore behavior.

## Brand Personality

Preserve T3 Code's existing identity and components. The user chose T3 Code itself
as the reference: session sidebar and chat on web, chat-first navigation on mobile.

## Anti-references

Do not reproduce the previous standalone session-picker UI or introduce a new
visual identity alongside T3 Code.

## Design Principles

- T3 is the source of truth for coding threads.
- Voice is another interaction channel, not another session manager.
- Keep the current thread visible and never silently change context.
- Settling is reversible and does not erase history.

## Accessibility & Inclusion

Retain upstream keyboard, focus, reduced-motion, and touch-control behavior.
New voice-specific controls use Polish labels. No additional accessibility needs
have been specified by the user.
